### F-B2 · Seven modals, one shared shell, four re-rolls — Severity: High
A shell primitive exists (`FundArcWalletModal.tsx:9–18` backdrop wrapper) but only the two Unified modals use it. `DepositModal.tsx:22–25`, `ProfileModal.tsx:43–46`, `AutonomousAgentModal.tsx:913–916` re-implement overlay inline. **Worst overlap:** `DepositModal` and `UnifiedDepositModal` are both mounted on AppPage, bind the same `depositAmountInput` state, and call the same underlying `handleDepositToGateway` (Direct: AppPage:953; via wrapper `handleManualGatewayDeposit` AppPage:460–462, 1026). ### F-B3 · Status chips: 8 CSS families, one status → three colors — Severity: High (user-visible inconsistency)

**Live CSS name collision:** `.badge` is defined twice with different rules — `styles.css:351` vs `app.css:6919` — and `app.css` silently wins by import order in `main.tsx`. Same class of bug: `.agent-pick-card` defined in both `app.css:386–410` (grid, 9px, radius 7) and `SignalSidebar.css:386–411` (flex, 12px, radius 8, accent left-border) — app.css:313 even comments "agent-picks-panel moved to SignalSidebar.css" while leaving the old rules live; and `@keyframes pulse-dot` is defined twice (`styles.css:196`, `index.css:224`).

### F-B7 · 14 raw `fetch` sites bypass `services/api.ts` — Severity: High (latent prod bug)

## 7. Proposed Design System (v2 — extend, don't replace)
